          Current initiative · Local Run Receipt

          One receipt for speed, token cost, privacy, and task quality.

          The first local-inference harness runs an immutable JSONL task pack against an OpenAI-compatible model endpoint. It permits loopback endpoints by default, refuses remote inference without an explicit opt-in, and records measurements without copying raw business inputs or model outputs into the receipt.

          Measured, not marketed Prompt, completion, and total tokens sit beside wall time and end-to-end output tokens per second. An optional compute-hour rate yields effective cost per million tokens and per strict exact match.
          Reproducible boundary The task-pack digest, model identity, runtime, hardware description, and active optimization travel with the result. A changed task pack cannot inherit an old comparison.
          Moat comparison A candidate run can compare with a baseline only when both receipts bind the same task digest. The useful question is quality per token on the work your business owns.
          Run the local harness Read the DFlash2 example

          DFlash2 is one example of the moving local-inference frontier, not a bundled Automoat dependency and not a universal speed claim. The harness keeps speculative decoding, quantization, caching, and future runtime techniques replaceable and proves each one on the actual hardware and task pack.

          Released capability · Moat Builder

          Whole-Record Check

          One current application of Automoat's core loop: turn bounded workflow evidence into an inspectable recommendation, then spend human attention only on material disagreement.

          A recommendation that agrees with its immutable case snapshot earns a Coverage Receipt. Missing actions or material evidence become Evidence Conflict cards with stable source IDs and correction-ledger context, so operators review the exception instead of rereading every record.

          Dallas validation set 30 versioned Dallas scaffold cases are stored as bounded, content-addressed snapshots.
          Quiet agreement 20 complete candidates produce Coverage Receipts with their action and source coverage.
          Visible exceptions Exactly 10 planted retrieval omissions produce 10 Evidence Conflict cards and no unexpected conflicts.
          Open the 30-case evidence Inspect report JSON

          Dallas validation boundary: this is a deterministic regression harness over versioned scaffold records, not a production model-accuracy benchmark. Dallas is not the full Automoat product.

          Truth In Advertising

          What is not built yet

          Built

          An interactive operating-plan questionnaire, bounded hosted planning synthesis, a browser-only deterministic fallback, a narrow permit-data proof wedge, artifact contracts, local run receipts, and an unattended evidence loop.

          Not built

          The plan does not yet install or operate a local model automatically. There is no production workflow runner or live baseline-versus-moat benchmark, and no evidence yet that the permit-data wedge generalizes into a durable data moat.

          Next best move: keep widening real Dallas import rows through the verified raw handoff, then capture the matching operator correction so the feedback loop stays executable.
