Local-first moat discovery and eval scaffolding

Find the operational memory a business can actually turn into a moat.

automoat is a local-first project for turning messy business workflow data into structured artifacts: business-first discovery outputs, normalized records, and eval scaffolds that can test whether a narrow workflow contains reusable, defensible judgment.

Broad Framing

What the product is trying to prove

The broader idea is not “AI for electricians.” It is that many businesses have local workflow memory, repeated edge cases, and decision patterns that generic models do not capture well. automoat is trying to make that claim testable.

  • Start from business pain and repeated judgment, not model choice.
  • Normalize the narrowest workflow that might contain a real operational edge.
  • Generate artifacts that make the edge inspectable before heavier product work.

Latest Signal

Most recent generated artifacts

South Dallas discovery variant

The newest business-first output is a second intake and generated discovery run for older-home electrical work across South Dallas and Oak Cliff. This proves the discovery contract can hold across more than one electrician profile without hand-editing outputs.

Row-derived reviewed labels

label_reviews.json is no longer just fixture-backed. It is now derived from normalized permit and inspection rows, which is the key bridge toward imported data.

Contract stability

The current project value is that the discovery, fixture, review, and eval contracts are now explicit enough to widen the sample inputs without rewriting the rest of the system.

Truth In Advertising

What is not built yet

Built

Narrow scope selection, artifact contracts, deterministic writers, two discovery variants, one normalized Dallas sample, one eval scaffold, and a shared unattended loop for keeping the generated status surfaces current.

Not built

No imported real Dallas record pipeline, no production application workflow, no live model benchmarking results, and no evidence yet that the Dallas wedge produces a durable moat in practice.

Next best move: import a wider Dallas permit and inspection sample into the normalized row contracts while keeping the discovery, label-review, fixture-pack, and eval outputs stable.
